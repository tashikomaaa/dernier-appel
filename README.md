# Dernier Appel

Des histoires vraies qu'on raconte à voix basse, au comptoir, quand la salle
s'est vidée. Espionnage, disparitions, objets dans le ciel, affaires qu'on n'a
jamais refermées.

**Seize minutes, un jeudi sur deux.**

## La règle du jeu

Le créneau est saturé de contenus qui confondent absence de preuve et preuve
d'autre chose. Ici, à chaque épisode, trois choses sont séparées et nommées
comme telles :

- **ce qui est établi** — sourcé, et sur quoi les historiens s'accordent ;
- **ce qui est débattu** — les hypothèses, qui les porte, ce qui les appuie
  *et* ce qui les contredit ;
- **ce qui n'est qu'une légende** — d'où elle vient, quand elle est apparue, et
  qui avait intérêt à la répandre.

Quand les sources s'arrêtent, on le dit. C'est souvent là que ça devient
intéressant. Trois sources minimum par épisode, dont au moins une universitaire
ou primaire, citées dans la description.
